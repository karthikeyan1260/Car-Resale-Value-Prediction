# 🚗 Car Resale Value Prediction

A machine learning web app that estimates the resale price of a used car from its specifications. Built with **LightGBM** for the model and **Flask** for the web interface.

## 📌 Overview

Enter a car's details (brand, model, year, mileage, power, fuel type and so on) and the app returns an estimated resale price. The model is trained on roughly **278K cleaned used-car listings** and served through a simple three-page Flask app.

## ❓ Problem Statement

Pricing a used car is largely guesswork. Sellers risk undervaluing a car and losing money, or overpricing it and waiting months for a buyer. Buyers have no easy way to tell whether a listing is fair. This project uses historical listing data to produce a consistent, data-driven price estimate.

## ✨ Features

- Predicts a resale price from 10 car attributes
- Clean landing page, input form and result page
- Trained model and label encoders saved to disk, so the app loads them without retraining
- Reproducible data cleaning and training in a single Jupyter notebook

## 🔄 How It Works

### 1. Data cleaning (`model.ipynb`)
- Kept cars with 50–900 PS power and registration years from 1950 to 2016
- Kept prices between 100 and 150,000
- Dropped irrelevant columns (name, A/B test flag, crawl dates, picture count, postal code, and similar)
- Removed duplicate listings
- Translated German values to English (for example `manuell` → `manual`, `benzin` → `petrol`, `kleinwagen` → `small car`)
- Filled missing categorical values with `not-declared`
- Saved the cleaned data as `autos_preprocessed.csv`

### 2. Feature engineering
Categorical columns (`gearbox`, `notRepairedDamage`, `model`, `brand`, `fuelType`, `vehicleType`) are label-encoded. The encoder classes are saved as `classes<column>.npy` so the Flask app encodes user input exactly as training did.

### 3. Model training
- Algorithm: `LGBMRegressor` (gradient boosting)
- Settings: `learning_rate=0.07`, `n_estimators=300`, RMSE objective
- Split: 70% train / 30% test
- Metrics: MAE, MSE, RMSE, R² and adjusted R²
- Trained model saved as `model.sav`

### 4. Web app (`app.py`)
1. `/` shows the landing page
2. `/predict_page` shows the input form
3. `/predict` reads the form values, encodes them with the saved classes, runs the model and renders the predicted price

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/car-resale-value-prediction.git
cd car-resale-value-prediction
```

### 2. Create a virtual environment and install dependencies
```bash
python -m venv venv
source venv/bin/activate        # On Windows: venv\Scripts\activate
pip install flask pandas numpy scikit-learn lightgbm
```

### 3. Generate the model files
Place the raw `Dataset.csv` in the project folder and run all cells in `model.ipynb`. This creates `model.sav` and the `classes*.npy` files.

> If you already have these files in the repo, skip this step. Use the same scikit-learn and LightGBM versions that were used for training, or the pickled model may not load.

### 4. Run the app
```bash
python app.py
```
Open **http://127.0.0.1:5000** in your browser.
